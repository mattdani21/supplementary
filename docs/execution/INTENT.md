# Intent

Turn a learner's noticed knowledge gap into a source-grounded course with audio, practice, verified mastery and later retrieval. Arc is the learner-facing experience over the GapOS engine. The gap, its evidence and its evolving capability are the core product objects.

## Critical journey

Define a gap → attach sources → diagnose → compile curriculum → listen and practise → receive verified feedback → demonstrate mastery → revisit retained capability. New work must keep this vertical slice intact.

## Next outcome

Make the existing web, worker and persistence components function as one reliable deployment, then replace demo identity before a public multi-user pilot. Completion is observable in persisted generation and mastery evidence; a rendered screen or a generated lesson alone does not establish success.

## Boundaries

Preserve pure domain logic, provider adapters, schema validation before persistence, evidence envelopes, forward-only migrations and existing budgets. Existing generated OpenAPI/JSON schemas stay the canonical public contracts. This package does not replace them with a parallel schema system.

Real-provider evaluations and public release remain separate existing gates. Authentication, rate limiting and untrusted proof execution need explicit technical closure before a public pilot. No additional paid service or public deployment is authorized by these documents.
